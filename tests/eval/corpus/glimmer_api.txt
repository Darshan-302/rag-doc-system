Glimmer API Rate Limits. The Glimmer public API allows 120 requests per minute per access token on the Starter plan and 900 requests per minute on the Orbit plan. When the limit is exceeded the server answers with HTTP status 429 and a Retry-After header giving the number of seconds to wait. Burst traffic is smoothed with a token bucket holding at most 40 extra requests. Enterprise customers may negotiate dedicated quotas. Rate limit counters reset at the top of every minute, UTC.
